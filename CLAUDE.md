# Onda — Site do Estúdio

Site institucional estático da Onda. O contrato canônico de trabalho está em
`AGENTS.md`; não o duplique aqui.

## Contexto rápido

- **Stack:** HTML5 + CSS3 vanilla + JavaScript ES6+. Sem framework, sem build,
  sem dependência pesada no bundle.
- **Estrutura:** `index.html` (raiz, obrigatório), `css/` (`styles.css`,
  `journey.css`), `js/` (`app.js`, `journey.js`, `image-slot.js`), `assets/`.
- **Design system "Tropical Tech":** `docs/brand/DESIGN_SYSTEM.md` +
  `docs/brand/BRANDING.md`. Tipografia Manrope; gradiente-assinatura
  `#88399A → #C05171 → #ED7735 → #FEA31B`.
- **Memória técnica:** `memoria-tecnica/` — consultar antes de investigar bug ou
  tomar decisão de arquitetura.
- **Validação:** conferência manual no navegador (desktop + mobile) —
  scrollytelling, navegação centralizada, carrossel mobile de serviços.
