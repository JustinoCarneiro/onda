Quando um sistema sob medida faz sentido

Planilhas, cadernos e ferramentas genéricas funcionam até a operação crescer. A partir de um certo ponto, cada frente do negócio passa a ter regra própria — e nenhuma delas conversa com a outra.

  • Dados e histórico espalhados entre planilhas, arquivos e pessoas diferentes.
  • Retrabalho para consolidar informação que já existe, só que em outro lugar.
  • Controle de acesso informal — quem pode ver ou editar o quê depende de combinação, não de regra do sistema.
  • Software genérico que resolve parte do processo e força a empresa a se adaptar ao resto.

O que construímos

Sistemas web modulares, entregues módulo a módulo a partir das regras reais da operação — cada perfil de usuário vendo e podendo fazer só o que deve.

  • ERP e backoffice — módulos financeiros, cadastros, operação e relatórios num só sistema.
  • RBAC dinâmico — perfis e permissões configuráveis pela própria coordenação, sem depender de desenvolvedor.
  • Dashboards operacionais — números da operação consolidados para quem decide.
  • Portais internos e externos — acesso segmentado para equipe, parceiros ou clientes.

Engenharia aplicada em produção

Evidência real do ERP do Instituto Melvin, em produção: 17 módulos, autenticação e RBAC dinâmico, testes automatizados e entrega contínua.

Backend: Java 21 · Spring Boot
Frontend: React · Vite · TypeScript
Banco: PostgreSQL · migrations com Flyway
Segurança: Spring Security · JWT · hash Argon2
Testes: 17 suítes E2E (Playwright) · 8 de backend (JUnit 5)
Entrega: CI/CD em GitHub Actions
